# divfw — 한국기업 예상배당 워크벤치

종목코드나 기업명을 넣으면 과거 배당흐름, 공시된 배당정책, 이익 가정을 바탕으로
향후 3개년 주당배당금과 현재가 기준 배당수익률을 계산합니다.

## 배포

Cloudflare Pages가 `main` 브랜치를 그대로 서빙합니다. 빌드 과정은 없습니다.

- `index.html` — 페이지 전체(스타일·스크립트 인라인)
- `stocks.json` — 상장 3,666종목 인덱스와 2021–2025 배당이력

## 배당정책 엔진

| 유형 | 계산식 |
|---|---|
| 배당성향형 | 배당성향 x 지배주주순이익 / 배당대상주식수 |
| 배당총액 약정형 | 약정 총액 / 배당대상주식수 |
| DPS 하한 + 시총연동형 | 하한 + (시가총액 x 환원율 x 현금배당비중) / 배당대상주식수 |
| FCF 비율형 | (순이익 x 영업CF배수 - CAPEX) x 환원율 x 현금비중 / 배당대상주식수 |

과거 배당은 DART 사업보고서 「배당에 관한 사항」 기준이고, 주가는 직접 입력합니다.
브라우저에서는 CORS 때문에 DART·거래소 API를 직접 호출할 수 없습니다.
